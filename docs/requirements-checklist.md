# Requirement → evidence checklist

Statuses: **PASS** (verified with the evidence named), **PARTIAL** (implemented, only partly verified),
**UNVERIFIED** (implemented, needs a manual check listed in `docs/manual-verification.md`), **BLOCKED**, **FAIL**.
Evidence paths are relative to the repo; `evidence/latest/` is regenerated by `scripts/collect_evidence.sh`
(tests, release build, snapshots) for the revision recorded in `evidence/latest/REVISION.txt`.
